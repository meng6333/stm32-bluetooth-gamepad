# STM32 双模蓝牙游戏手柄

基于 STM32F103C8T6（标准库）设计的游戏手柄，支持 USB HID 直连电脑免驱作为标准手柄，也可通过 HC-05 蓝牙与小车主从配对进行遥控。

## 功能
- USB HID：移植 STM32 USB HID 协议栈，8 字节上报报文（按键位图、方向帽、双摇杆 X/Y、左右扳机 Z 轴），电脑免驱识别。
- 摇杆/扳机采集：ADC1 六路通道，开机均值中点校准，软件死区剔除 + 一阶低通滤波后映射到 HID 报文。
- 按键：15 个按键扫描与上升沿消抖（方向帽、动作键、肩键、摇杆下压等）。
- 蓝牙遥控：USART1 经 HC-05 配对，支持包头包尾帧、十六进制、换行符等指令格式，联动蓝牙小车。
- OLED 菜单：摇杆/扳机实时画面、死区与滤波强度调节、版本信息与蓝牙配置；WS2812B 状态灯。

## 目录
- User：主程序与中断服务
- Hardware：ADC、按键、OLED、串口、WS2812B 等驱动
- System：延时等系统模块
- Library：STM32 标准库外设驱动及 USB Core / HID 协议栈
- Start：启动文件与内核支持
- Firmware：编译生成的 HEX 固件

## 开发环境
Keil MDK、STM32F103C8T6、C 语言标准库；PCB 嘉立创打样，自主焊接组装与烧录调试。
